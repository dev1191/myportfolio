## 1. Visual World

**Name:** STITCHED  
**Aesthetic:** High-end technical interface. Precision-first. The composition is built as a modular grid of rectilinear "stitched" cells — separated by a 1 px gap laid on a background-colored rule — giving the illusion of fine-line borders between every panel. The vocabulary references CAD software, blueprint drafting, and developer terminals.

**Character:** The design does not decorate. Every element justifies its existence structurally. Hover states are restrained (a primary-colored inset border) rather than explosive. Typography is uppercase, monospace where it labels; wider-spaced, heavy where it headlines. Motion is purposeful entrance animation only — nothing ambient.

**Primary mode:** Experience → Persuade. The portfolio IS the artifact; the UI recedes. The first viewport is identity; subsequent sections are evidence.

## 5. Layout

### Page shell
- Root div: `min-h-screen bg-background`
- `<main>`: `pt-16 max-w-container-max mx-auto border-x border-outline-variant` — creates the central column with vertical side rails.
- Footer: same `max-w-container-max mx-auto border-x` — mirrors the main column.
- Nav: `fixed top-0 left-0 w-full z-50` — full-width sticky overlay.

### The stitched grid system
```
.stitched-grid  → display: grid; gap: 1px; background: outline-variant;
.stitched-module → background: background; position: relative;
```
The `1px` gap on a background-colored grid container creates the "stitched" border illusion without actual borders between cells. Each module is an individual background-colored cell; the container's background color shows through the gap as a hairline.

### Section layouts

## 6. Component Patterns

### stitched-module hover
Every `.stitched-module` has a pseudo `::after` layer that transitions from `border-transparent` to `border-primary` on hover. This creates an in-place inset highlight without layout shift.

```css
.stitched-module::after {
  content: "";
  position: absolute; inset: 0; pointer-events: none;
  border: 1px solid transparent;
  transition: border-color 200ms;
}
.stitched-module:hover::after {
  border-color: var(--primary);
}
```

### Primary CTA button
```
bg-primary text-on-primary font-label-mono px-margin-sm py-{2–3} font-bold
hover:opacity-80 | hover:bg-primary/90
transition-all
```
Square corners (no border-radius). Uppercase monospace label.

### Ghost / outline button
```
border border-outline-variant text-on-surface font-label-mono
hover:border-primary transition-colors
```
Square corners. Used for secondary actions (GitHub link in project cards).

### Tag / badge
```
font-label-mono border border-primary text-primary px-2 py-1 text-[10px]
```
Used in project cards to show the tech stack.

### Nav link (active)
```
font-label-mono text-primary border-b-2 border-primary pb-1
```

### Nav link (inactive)
```
font-label-mono text-on-surface-variant hover:text-primary transition-colors
```

### Input / Textarea
```
w-full bg-surface-container border border-outline-variant text-on-surface
p-base focus:border-primary focus:ring-0 outline-none
placeholder:text-surface-variant font-jetbrains text-sm
```
Square corners. No ring on focus — primary border only.

### Theme toggle button
Wraps `stitched-module` pattern with icon rotation on hover:
- In dark mode → shows Sun icon, `group-hover:rotate-45`
- In light mode → shows Moon icon, `group-hover:-rotate-12`

### Avatar frame
```
w-64 h-64 border-2 border-primary p-2 overflow-hidden bg-surface-container
```
Square. Inner image: `grayscale hover:grayscale-0 transition-all duration-700`.
Decorative corner brackets: `absolute -top-4 -right-4 w-12 h-12 border-t-2 border-r-2 border-primary` (and mirrored bottom-left).

### Project card image
```

img: grayscale opacity-50 → grayscale-0 opacity-100 (on group-hover)
     scale-105 → scale-100 (on group-hover)
     transition-all duration-700
```
Overlay: `absolute inset-0 bg-primary/10 opacity-0 → opacity-100` on hover.

### Stat cell
```

p (number): font-label-mono text-primary text-xl mb-1
p (label): font-label-mono text-[10px] text-on-surface-variant
```


## 7. Motion

### Library
`@vueuse/motion` (v3) — directive-based, Composition API.

### Entrance animations (existing)

| Element | Initial | Enter | Duration |
|---|---|---|---|
| Hero text block | `opacity: 0, y: 20` | `opacity: 1, y: 0` | 800 ms |
| Hero avatar | `opacity: 0, scale: 0.9` | `opacity: 1, scale: 1` | 1000 ms |

### Transition animations (Vue `<transition>`)
Mobile nav overlay: slide in from right.
```
enter: opacity-0 translate-x-full → opacity-100 translate-x-0 (300 ms ease-out)
leave: opacity-100 translate-x-0 → opacity-0 translate-x-full (200 ms ease-in)
```

### CSS transitions
- All hover state changes: `transition-all duration-300` (modules) or `transition-colors duration-200` (borders).
- Image reveal on project card: `transition-all duration-700`.
- Theme color change: `transition: background-color 0.3s ease, color 0.3s ease` on `html`.
- Icon rotation in ThemeSwitcher: `transition-transform`.

### Motion rules
- No ambient or looping animation.
- Entrance motion is applied only to above-the-fold elements (Hero).
- All hover transitions are sub-300 ms for responsiveness.

## 11. Theme system

Implemented via `useTheme` composable:
- Reads `localStorage.getItem('theme')` on mount.
- Falls back to `window.matchMedia('(prefers-color-scheme: dark)')`.
- Toggles `document.documentElement.classList` between `.dark` / no class.
- Persists choice to `localStorage`.

Theme classes are on `<html>`. Tailwind's `dark:` variant is NOT used — instead, Tailwind's `@theme` maps CSS custom properties, and the `.dark` class redefines those properties. All color tokens are always referenced as `var(--token)` via the Tailwind `@theme` bridge.

## 12. Absolute don'ts (design bans)

- **No border-radius** — all corners are square. This is a pinned aesthetic rule.
- **No secondary palette** — no blues, reds, yellows. Only the green-black-white system.
- **No decorative gradients** — the primary/10 overlay on project cards is functional (hover reveal), not decorative.
- **No ambient animation** — no looping, pulsing, or particle effects.
- **No shadows** — depth comes from the stitched border system, not box-shadows.
- **No serif fonts** — the font world is JetBrains Mono + Geist only.
- **Do not alter** factual content (project descriptions, company names, dates, links) without asking.
